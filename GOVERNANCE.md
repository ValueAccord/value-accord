# Governance

Value Accord is in a bootstrap phase. Maintainers make decisions by documented rough consensus, with security and user safety able to block a release. Protocol changes require a numbered RFC, public review period, compatibility analysis, and recorded rationale. No single provider should control routing semantics, conformance certification, or the specification trademark.

Before a public working group forms, the project will define maintainer nomination/removal, conflict-of-interest disclosure, appeals, voting fallback, specification IP terms, and neutral stewardship. This document is a starting constraint, not a claim that such an institution already exists.
