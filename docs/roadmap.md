# Roadmap

## Phase 0 — Sandbox foundation (current)

Exact-amount EUR intents, virtual USD quotes, deterministic routing, in-memory holds, signed packets, receipts, refunds, disputes, and lifecycle tests.

## Phase 1 — Protocol hardening

JSON Schema, integer minor units, negative conformance fixtures, durable replay abstraction, provider signatures, failure injection, property tests, privacy review, and algorithm agility.

## Phase 2 — Independent interoperability

Two independently written implementations, public test vectors, conformance runner, interoperability event, neutral governance proposal, and specification license decision.

## Phase 3 — Controlled pilots (gated)

Only after legal analysis, threat-model review, independent security audit, qualified regulated partners, data-protection design, operational controls, and explicit project approval. No date or outcome is promised.
