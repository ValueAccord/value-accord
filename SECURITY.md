# Security Policy

This pre-release sandbox is not approved for real value or sensitive information. Please do not test it with real accounts or credentials.

Report suspected vulnerabilities privately to the future security contact before public disclosure. Until a private channel is established, do not publish exploitable details; open a minimal issue requesting maintainer contact. Include affected component/version, reproduction steps using synthetic data, impact, and suggested mitigation. No bug bounty or response SLA is currently offered.
