# Contributing

Thank you for improving Value Accord. Start with an issue or short design note before large changes. Keep the sandbox synthetic: never add real credentials, personal financial data, production endpoints, or language implying regulatory approval.

Contributions should include focused tests, explain protocol compatibility and threat-model impact, and update the relevant RFC text. Run `node --test tests/*.test.js` and the website build before proposing a change. Commits must comply with the Code of Conduct. By contributing code, you agree it is licensed under Apache-2.0; specification text remains subject to the separate notice in RFC-0001 until a final legal choice is made.
